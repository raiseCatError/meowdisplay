# Getting help

For the current release, see [platform availability](README.md#platform-availability--november-2-2026).
iPhone/iPad 2.0 is on the App Store. The current Mac 2.0 download retains its
beta 1 artifact label; Android 2.0 is in closed testing. Both mobile 2.0 apps need the Mac 2.0 sender for new features;
Android 2.0 cannot use Mac 1.20.0.

For a bug report, include both app versions, OS versions, device models,
connection route, and whether it happens in Mirror, Extend or Windows.
Remove private addresses and personal screen content from logs and screenshots.


| You have… | Go to |
| --- | --- |
| A setup or usage question | [Setup guide](https://meowdisplay.app/docs.html) and [Support](https://meowdisplay.app/support.html) |
| A reproducible bug | [Bug report](https://github.com/raiseCatError/meowdisplay/issues/new?template=bug_report.yml) |
| A feature idea | [Feature request](https://github.com/raiseCatError/meowdisplay/issues/new?template=feature_request.yml) |
| A **security or privacy vulnerability** | **Private** vulnerability reporting — never a public issue. See [SECURITY.md](SECURITY.md). |
| A translation to contribute | [Translations in CONTRIBUTING.md](CONTRIBUTING.md#translations) |
| A development question | [CONTRIBUTING.md](CONTRIBUTING.md) and [ARCHITECTURE.md](ARCHITECTURE.md) |

See [Features](https://meowdisplay.app/features.html) for what MeowDisplay
currently supports, and [CONTRIBUTING.md](CONTRIBUTING.md) if you want to help.
