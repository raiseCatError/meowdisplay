# Getting help

| You have… | Go to |
| --- | --- |
| A setup, permission or usage question | [Setup guide](https://meowdisplay.app/docs.html) and [Support](https://meowdisplay.app/support.html) |
| A reproducible bug | [Bug report](https://github.com/raiseCatError/meowdisplay/issues/new?template=bug_report.yml) |
| A request for a specific improvement on a supported platform | [Feature request](https://github.com/raiseCatError/meowdisplay/issues/new?template=feature_request.yml) |
| An exploratory or unplanned idea | [Idea / exploration](https://github.com/raiseCatError/meowdisplay/issues/new?template=idea.yml) |
| A documentation correction | [Documentation issue](https://github.com/raiseCatError/meowdisplay/issues/new?template=documentation.yml) |
| A physical-device compatibility or QA observation | [Device testing / compatibility](https://github.com/raiseCatError/meowdisplay/issues/new?template=device_testing.yml) |
| A **security or privacy vulnerability** | **Private** vulnerability reporting — never a public issue. See [SECURITY.md](SECURITY.md). |
| A translation to contribute | [Translations in CONTRIBUTING.md](CONTRIBUTING.md#translations) |
| A development question | [CONTRIBUTING.md](CONTRIBUTING.md) and [ARCHITECTURE.md](ARCHITECTURE.md) |

MeowDisplay currently focuses on a Mac sender with receivers on Mac, iPhone,
iPad and Android. Windows and Linux support are **not planned**; the
[idea tracker #84](https://github.com/raiseCatError/meowdisplay/issues/84)
is not a release commitment.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a public issue. Never
share unredacted diagnostic logs, network addresses, private device names,
pairing codes or personal screen content.

See the [features page](https://meowdisplay.app/features.html) for the
currently supported experience.
